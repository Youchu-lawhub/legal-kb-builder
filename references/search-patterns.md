# 常见检索模式速查

Agentic 检索时的工具调用模式速查表，供 QoderWork 快速参考。

## 前置步骤：识别书籍类型

在使用任何检索模式之前，**必须先确认文献的书籍类型**。这决定了后续使用哪种检索策略。

```
Step 0: 读取文献库的第一个文件的前 200 行
Step 1: 查找目录/Contents 结构
Step 2: 判断类型：

  目录以"第X条"为主线 → 条文驱动类（法典评注/司法解释适用）
    → 记录条文范围（如第1条至第69条）
    → 后续搜索中区分"本书的结构条文"和"正文引用的其他法律条文"
    
  目录以"第X章""第X节"为主线 → 章节驱动类（专著/教科书）
    → 记录章节列表
    → 后续以概念和章节为检索入口
    
  目录以案例名称/案号为主线 → 案例汇编类
    → 记录案例清单
    → 后续以案例名/案号/案由为检索入口
    
  目录以专题/问题为主线 → 实务指引类
    → 记录专题列表
    → 后续以专题名/关键词为检索入口
    
  目录以法规名称/法规编号为主线 → 法规汇编类
    → 记录收录的法规清单
    → 后续以法规名称/发文字号/关键词为检索入口
    
  目录以"第X编""第X章"系统章节 + 课后习题/案例研讨为主线 → 教科书类
    → 记录编/章/节结构
    → 后续以概念/知识点/章节为检索入口（逻辑同章节驱动，但粒度更细）

Step 3: 将类型信息保持在上下文中，所有后续检索都要参照
```

## 模式一：本书条文精确检索（条文驱动类专用）

场景：用户问"第X条说了什么"、"查一下第X条的评注"，且 X 在本书目录范围内

```
Step 1: 确认 X 在本书结构条文范围内（如第1-69条）
Step 2: Grep "第{X}条" → 获取所有匹配行及行号
        同时 Grep 中文数字格式（如"第三十二条"）
Step 3: 筛选标题行：
        - 独立成行或以 # 开头的位置
        - 行首出现的位置（非正文中间的引用）
        - 紧跟【条文主旨】或【条文】的位置
Step 4: Read 该位置起 100-200 行 → 获取条文正文+评注
Step 5: 若评注未结束，继续 Read 直到遇到"第{X+1}条"标题
```

关键词模板：`第{N}条`、`第{中文数字}条`

## 模式二：关联法条检索（所有类型通用）

场景：用户问"本书中关于民法典第584条怎么说的"（584不在本书结构范围内）

**注意：这是查本书中对该法条的引用论述，不是查本书的第584条！**

```
Step 1: 确认目标条文号不在本书结构范围内 → 这是关联检索
Step 2: Grep "第{M}条" 或更精确地 Grep "《XXX》第{M}条"
Step 3: 对每个匹配，Read 前后 30 行上下文
Step 4: 筛选：上下文是否包含对该法条的实质讨论（而非仅路过提及）
Step 5: 提取讨论段落，标注出处
```

关键词模板：`第{M}条`，或 `《法律名称》.*第{M}条`

**易错警示**：如果在一本69条司法解释的书中搜索"第584条"并找到结果，这不代表该书有第584条——它只是引用了民法典第584条。

## 模式三：学者观点检索

场景：用户问"XXX怎么看"、"XXX的观点"

```
Step 1: Grep "{学者姓名}" → 获取所有提及位置
Step 2: 对每个位置 Read 前后 20-30 行上下文
Step 3: 筛选上下文中包含目标主题关键词的片段
Step 4: 提取完整论述段落
```

关键词模板：`{学者姓名}`，配合主题词筛选。注意查 `keyword-expansion.yaml` 中的学者别名。

## 模式四：概念定义检索

场景：用户问"什么是XXX"、"XXX的构成要件"

```
Step 1: 从 keyword-expansion.yaml 获取同义词列表
Step 2: Grep 每个同义词 → 收集所有匹配位置
Step 3: 优先级排序：
        a. 章节标题命中 → 最可能是系统论述（章节驱动类书籍优先看这个）
        b. 条文标题命中 → 最可能是法条评注（条文驱动类书籍优先看这个）
        c. 首次出现位置 → 最可能是定义
        d. 高频出现文件 → 最可能是专题讨论
Step 4: Read 高优先级位置的完整段落
Step 5: 提取：定义 → 构成要件 → 法律效果 → 争议问题
```

## 模式五：对比分析检索

场景：用户问"A和B有什么区别"、"对比不同观点"

```
Step 1: 确定对比维度（概念 vs 概念 / 学者 vs 学者 / 书 vs 书）
Step 2: 启动并行 Task：
        Task A → 在来源A中检索主题（使用对应书籍类型的策略）
        Task B → 在来源B中检索主题（使用对应书籍类型的策略）
Step 3: 汇总两个 Task 的结果
Step 4: 整理对比：共识点 / 分歧点 / 各自理据
```

## 模式六：引用链追踪

场景：文本中出现"参见第X条"、"详见XXX"

```
Step 1: 识别引用标记：
        - "参见第X条" / "见第X条"
        - "详见XXX一书"
        - 脚注/尾注中的引用
Step 2: 判断引用类型：
        - 如果"参见第X条"的 X 在本书范围内 → 用模式一（本书条文检索）
        - 如果 X 不在本书范围内 → 这是交叉引用，记录但不追踪（本书中查不到）
Step 3: 将引用内容附在原始内容之后
```

## 模式七：案例检索（案例汇编类 / 司法解释适用类）

场景：用户问某个案例的裁判要旨或评析

```
Step 1: Grep 案号（如"(2020)最高法民终XXX号"）
Step 2: 若无案号，Grep 当事人名称或关键事实
Step 3: Read 匹配位置前后 50 行 → 获取案例评析
Step 4: 若文献中只是引用，提取引用上下文中的评述
Step 5: 对于司法解释适用类书籍，案例通常在每个条文的【案例】子节下
```

## 模式八：司法解释条文子结构检索（司法解释适用类专用）

场景：用户问某条的具体子结构内容，如"第32条的争议观点"、"第10条的实务问题"

```
Step 1: 先用模式一定位到"第{N}条"的起始位置
Step 2: 在该条范围内 Grep 子结构标记：
        - 【条文】/ 【条文主旨】→ 条文正文和概述
        - 【条文概览】→ 整体介绍
        - 【争议观点】→ 学术争议
        - 【理解与适用】→ 最高院的官方解读
        - 【实务问题】→ 实践中的难点
        - 【案例】→ 典型案例
Step 3: Read 对应子结构的内容段落
```

## 工具选择指南

| 需求 | 工具 | 参数要点 |
|------|------|---------|
| 找关键词位置 | Grep | `pattern`, `output_mode: "content"`, `-n`, `-C 3` |
| 列出所有文件 | Glob | `pattern: "**/*.md"` |
| 读取指定段落 | Read | `offset` + `limit` 精确控制范围 |
| 并行搜索多文件 | Task | 每个子Agent负责一组文件 |
| 统计出现次数 | Grep | `output_mode: "count"` |

## 不同书籍类型的文档结构

### 法典评注类
```
# 第X条 【条文简称】
条文原文...
## 一、规范目的
## 二、构成要件
## 三、法律效果
## 四、举证责任
## 五、关联条文
```

### 司法解释适用类
```
# 第X条 【条文主旨】
## 【条文】
  司法解释条文原文...
## 【条文主旨】
## 【条文概览】
## 【争议观点】
## 【理解与适用】
  最高院的官方解读...（这是最有价值的部分）
## 【实务问题】
## 【案例】
```

### 学术专著类
```
# 第X章 章名
## 第一节 节名
### 一、概述
### 二、历史沿革
### 三、比较法
### 四、要件分析
### 五、法律效果
```

### 案例汇编类
```
# 案例名称
## 案件事实
## 裁判要旨
## 评析
### 1. 争点分析
### 2. 法律适用
### 3. 学说讨论
```

### 实务指引类
```
# 专题一 XXX
## 一、基本概念
## 二、操作流程
## 三、注意事项
## 四、常见问题
## 五、典型案例
```

### 法规汇编类
```
# 法规名称（如：《关于XXX的若干规定》）
## 发文信息（发文字号、发布日期、施行日期）
## 法规正文
  第一条 ...
  第二条 ...
## 编者注 / 适用说明（如有）
```

### 教科书类
```
# 第X编 编名
## 第X章 章名
### 第一节 节名
#### 一、概念与特征
#### 二、历史沿革
#### 三、比较法
#### 四、构成要件
#### 五、法律效果
### 思考题 / 案例研讨
```
